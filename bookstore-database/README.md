# Bookstore Database
   
   A Python script that uses SQLite to store book sales data 
   and run queries to find total copies sold, the best-selling 
   book, and the average book price.
   
   ## What I learned
   - Working with SQLite databases in Python (sqlite3 module)
   - Creating tables and inserting data with executemany()
   - Running SQL queries (SUM, ORDER BY, AVG) from Python
   - Formatting numeric output
